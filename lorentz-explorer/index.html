Lorentz oscillator: absorption and refractive index

Pick an example or set the number density N, the background index nbg and up to three oscillators (centre wavelength, linewidth, oscillator strength, mass, charge). The page computes α(ω) and n(ω) exactly from ε̃r = nbg² + χ̃ and can overlay the two standard approximations: the dilute expansion (|χ̃| ≪ 1) and the near-resonance Lorentzian (γ ≪ ω0). Example spectrum: fused silica glass

The same model for a real glass: Malitson's Sellmeier terms for fused silica turned into two UV electron oscillators and one IR Si–O vibration, with linewidths added by hand. Fixed example; load "Fused silica glass" above to change it.

Same zoom and hover as above.

Glass is transparent between its UV electronic absorption (below ~0.2 µm) and its IR lattice absorption (above ~4 µm); the visible band (grey) sits inside that window, where n falls slowly with wavelength (normal dispersion, Cauchy's formula). Each resonance makes the same dispersive wiggle in n as the Na line, just much broader. The model n (blue) matches the measured Sellmeier curve (orange dashed) to about 10⁻⁵ in the window. The model α in the window is far too large: Lorentzian tails fall off only as a power of the detuning, while real absorption edges fall off exponentially, so the depth of the window (and α in the visible) is not quantitative. Real fused silica has α ≪ 1 m⁻¹ in the visible; the blue band marks roughly where UV-grade silica transmits.

Equations

  1. Driven charge on a spring

    d²x̃/dt² + γ dx̃/dt + ω0² x̃ = (q/m) Ẽ0 e−iωt  ⇒  x̃ = (q/m) Ẽ / (ω0² − ω² − iγω)

    q and m are the charge and mass that oscillate: an electron (q = e, m = me) for UV/visible lines, an ion pair (reduced mass, effective charge) for IR vibrations. The nuclear charge of an atom or ion does not enter q; it sets ω0.

  2. Susceptibility and permittivity

    χ̃ = Σj (N qj² fj / ε0mj) / (ωj² − ω² − iγjω),  ε̃r = nbg² + χ̃

    With nbg = 1 and one q, m this is the usual ε̃ = ε0(1 + χ̃). The page writes Sj = N qj²fj/ε0mj (units rad² s⁻²).

  3. Complex wavenumber, absorption coefficient and index, solid curves

    k̃ = ω√(ε̃μ0) = (ω/c) √ε̃r = k + iκ,  n = ck/ω = Re √ε̃r,  α = 2κ = (2ω/c) Im √ε̃r

    I = I0 e−αz; α is in m⁻¹ and 1/α is the distance over which the intensity falls to 1/e. The square root is the branch with Im ≥ 0.

  4. Dilute limit, |χ̃| ≪ 1, red dashed

    n ≈ nbg + Re χ̃ / 2nbg,  α ≈ (ω / c nbg) Im χ̃
    n = 1 + (Nq²/2ε0m) Σ fj(ωj² − ω²) / [(ωj² − ω²)² + γj²ω²],  α = (ω²Nq²/ε0mc) Σ γjfj / [(ωj² − ω²)² + γj²ω²] (nbg = 1)

    Fine for gases; fails for glass, where |χ̃| ≈ 1. The table says which case you are in.

  5. Near one resonance, ω0 + ω ≈ 2ω0 and γ ≪ ω0, orange dashed

    α = (Nq²f / 2ε0mc nbg) · (γ/2) / [(ω − ω0)² + (γ/2)²]
    n − nbg = (Nq²f / 4ε0mω0nbg) · (ω0 − ω) / [(ω − ω0)² + (γ/2)²]

    α is a Lorentzian whose FWHM in ω is γ. In the code, each oscillator's Lorentzian is summed.

  6. Peak, extrema and the anomalous-dispersion region

    αmax = Nq²f / (ε0mcγnbg) at ω = ω0
    n largest at ω0 − γ/2, smallest at ω0 + γ/2;  α there = αmax/2;  anomalous-dispersion width = γ (Δν in Hz)
    (n − nbg)max = Nq²f / (4ε0mω0γnbg) = αmax c / 4ω0 = αmax λ0 / 8π

    αmax does not depend on ω0; (n − nbg)max falls as 1/ω0.

  7. Units and conversions

    ω = 2πν,  ν = c/λ,  ω = 2πc/λ,  ν̃ (cm⁻¹) = 10⁷ / λ(nm),  γ = 2π ΔνFWHM,  1 u = 1822.89 me

    A linewidth quoted in Hz is Δν; the γ in the formulas is in rad/s. Hz and rad/s are both s⁻¹, so the 2π is easy to drop.

  8. Sellmeier and Cauchy

    γ → 0:  n² = 1 + Σj Bj λ² / (λ² − λj²),  Bj = Sj / ωj² = Nqj²fj / ε0mjωj²
    ω ≪ ω0, dilute:  n ≈ 1 + A(1 + B/λ²)

    The glass examples use published Sellmeier coefficients (fused silica: I. H. Malitson, J. Opt. Soc. Am. 55, 1205 (1965); N-BK7: Schott data sheet) converted with this relation. That fixes N q²f/m for each term; how you split it among N, f, q and m is a choice.

Notes on the examples

  • Na vapour: a dilute gas with N = 10¹⁷ m⁻³, Δν = 100 MHz and f = 1, simple round numbers for a single line. The real Na D₂ line has f ≈ 0.64 and a natural width of about 10 MHz.
  • He⁺: the 1s→2p line of a hydrogen-like ion (Z = 2): λ₀ = 30.38 nm, f = 0.416, natural width A/2π ≈ 1.6 GHz (A ≈ 1.0×10¹⁰ s⁻¹, 16× hydrogen's Lyman-α). An ionised gas also has free electrons, which add a term with ω0 = 0 that lowers n; add it as an oscillator with a very long λ₀ if you want to see it.
  • Air: one effective UV oscillator (λ₀ = 77 nm, f = 4.02, N for 15 °C and 1 atm) chosen so that n − 1 = 2.77×10⁻⁴ at 589 nm with the measured slope between 400 and 700 nm. Real air absorbs below ~200 nm through many O₂ and N₂ bands; this single line only reproduces their effect on n in the visible.
  • Glass: N = 2.2×10²⁸ m⁻³ (SiO₂ units in fused silica, used as an effective value for BK7). UV widths are 2% of ν₀, the IR width is 60 cm⁻¹; both are illustrative.
