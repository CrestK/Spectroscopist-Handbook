Exam scan check

Load a scanned stack of exams as a PDF and, if you have one, a blank copy of the exam. The page compares every scanned page with the blank one and lists missing, duplicated, out-of-order, upside-down and blank pages. Then turn the pages that need it and save a corrected PDF. Everything happens in this browser: the files are not uploaded, and the page is locked so it cannot send them anywhere. Methods are at the bottom.

    Methods

    The check is a port of check_scan.py and gives the same report: the thumbnails, the blur and the paper level are computed exactly as with Pillow and numpy, and on a test stack of 61 pages every similarity agrees with the Python script to 7×10⁻⁶ and the page sequence is identical. The PDF pages are drawn with pdf.js instead of MuPDF, which can shift the similarities slightly.

    1. Thumbnails and ink map

      page drawn at 30 dpi in grayscale → landscape turned 90° counter-clockwise → 170 × 220 pixels (Lanczos)
      a = gray / 255,  p = 90th percentile of a (the paper),  ink = clip((p − a) / p, 0, 1),  then a Gaussian blur with σ = 1.5 pixels

      Dividing by the paper level makes a dark and a light scanner give the same ink map. The blur makes the comparison tolerant to small misalignments and to thin pen strokes.

    2. Similarity of a scanned page a to a template page b

      s = max over shifts (Δx, Δy) ∈ {−4, −2, 0, 2, 4}² of Σ (aΔ − āΔ)(b − b̄) / (‖aΔ − āΔ‖ ‖b − b̄‖)

      A normalised correlation over the central 162 × 212 pixels, so 1 means identical layouts. Handwriting lowers it a little for every template page alike.

    3. Upside-down pages

      turned 180° if maxk s(rotated a, bk) > maxk s(a, bk) + 0.05

      A page that was drawn landscape and then still matches better upside down was sideways the other way; the page section turns it 90° clockwise.

    4. Blank pages

      blank if ink fraction (pixels with ink > 0.2) < max(0.0005, 0.15 × median of the template pages)

      Empty backs from duplex scanning are set aside and not matched, unless the exam itself has a blank page.

    5. The most likely page sequence

      cost = Σi 3 (maxk sik − si,gi mod n) / max(maxk sik − mediank sik, 0.02) + 4 × (skipped positions) + 4 × (repeats)

      The stack should read 1, 2, …, n, 1, 2, …; each scanned page i gets a global position gi = exam × n + page that never goes back, chosen by dynamic programming over the whole stack, so one ambiguous page cannot derail the rest. At most 2n positions are skipped at once, and the stack should end on the last page of an exam.

    6. Second pass

      Each template page is rebuilt as the pixel median of every scanned copy assigned to it (when there are 3 or more). Handwriting differs from student to student and cancels out; the printed page remains, with this scanner's look, and all pages are matched again.

    7. Report

      A jump in position is a missing page, a repeated position a duplicate. A page whose best-matching template page is not the one its position calls for is marked "looks most like page …"; one whose best match leads the second best by less than 0.03 is "low confidence". With "the first n scanned pages" in place of a blank exam those pages are the template, so they must be one complete exam.

    8. Turning pages

      /Rotatenew = (/Rotatecurrent + turn) mod 360,  turn clockwise in degrees

      As rotate_pdf.py: rotation is a metadata change, so page content is never re-rendered. The new page entries are written as an incremental update after the original bytes, with their own cross-reference section, which keeps encrypted PDFs encrypted. Before the file is offered, pdf.js reads it back and every page's rotation is checked.

    Files and limits

    • Privacy: the PDFs are read with the browser's file picker and stay in this tab's memory. The page's Content-Security-Policy allows connections only to this site's own files (pdf.js and its decoders), so the browser itself blocks any attempt to send data elsewhere. Closing the tab discards everything.
    • PDF reading uses pdf.js 6.4.299 (Mozilla, Apache 2.0), bundled with the page, with its JBIG2, CCITT and JPEG 2000 decoders for scanner images.
    • Password-protected PDFs open after you type the password. Turning pages keeps the encryption; it does not work when an encrypted PDF keeps its pages in compressed object streams (the page says so).
    • Large stacks take a while: every page is drawn once. The comparison runs in parallel in the background and can be stopped.
    • To use the page offline, save its folder and serve it with any local web server (for example python -m http.server); browsers do not run its modules straight from disk.
